# Getting Started with the API Server

This project contains the backend logic and the API for the application. It was bootstrapped to provide data and handle business logic for the React client.

## Available Scripts

In the project directory, you can run:

### `./mvnw clean compile exec:java`

Runs the server.\
The API will be at [http://localhost:8080](http://localhost:8080).

### `npm test`

Launches the test runner in the interactive watch mode.\
See the section about [running tests](https://facebook.github.io/create-react-app/docs/running-tests) for more information.
